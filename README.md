# OOP Flight Search App

A Python GUI application for searching and managing flight information.

## Features
- Search flights by flight number
- View all flights in a table
- Calculate revenue, costs, and profit
- Ticket class hierarchy (Economy Light, Standard, Comfort, Business)

## OOP Concepts Used
- **Encapsulation**: Private attributes with getters/setters
- **Inheritance**: Ticket class hierarchy
- **Composition**: Flight contains Ticket objects

## Requirements
- Python 3.x
- tkinter (included with Python)

## How to Run
```bash
python3 flight_app_pro.py
```

## Files
- `flight_app_pro.py` - Main application
- `Flight_numbers.csv` - Flight data
